Purpose

Style the sidebar and make it look like a dashboard navigation panel.

Layout Requirements

Sidebar should be:

position: fixed
left: 0
top: 0
height: 100vh
width: 220px
Styling

Sidebar must include styling for:

background color
menu spacing
hover effects
active menu highlight

Example theme:

Background: #0F172A
Text: white
Hover: light blue
CSS Classes

Developer must create styles for:

.sidebar
.sidebar-header
.sidebar-menu
.sidebar-item
.sidebar-item:hover
.active-link
.logout
